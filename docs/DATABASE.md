# Database

## Base tables

`rooms`, `room_users`, `player_inventory`, `room_players`, `live_auction_state`, `user_squads`, `bid_history` were created from [archive/DATABASE_SETUP.md](archive/DATABASE_SETUP.md) and extended by later files. That guide's table definitions predate several columns (squad sizes, `purchased_at`, `auto_hammer`, `ready_to_start`, `is_paused`); the files below add them.

Order matters because files 3 and 5 also define `place_auction_bid`; file 16 must be its last definition (it replaces file 6's, reading the room's bid steps). Files 3, 5 and 9 define `auction_hammer_advance`; file 9 is the last. File 15 also redefines `auction_pick_next_lot` (also in file 3) and must stay after it. Do not run an earlier file alone against a live database.

Not in the runner: `FIX_READY_BUTTON.sql` (one-off realtime publication fix), `place_auction_bid.sql` and `finalize_auction_timer.sql` (superseded, reference only), `player_inventory_ipl2026_seed.generated.sql` (data seed, generated by `npm run import:ipl2026`).

## Environments

Production is the only database today. Prefer a second Supabase project for staging and point `SUPABASE_DB_URL` at it while testing schema changes.

## Testing database rules

`place_auction_bid` and the host functions need a signed-in user (`auth.uid()`). `npm run db:test` runs the rule tests in `scripts/db-tests/` (291 checks: bid rules, security attacks, auto-sell, undo, pause and close, co-hosts, cleanup, sets, room settings, drafts, ILT20 lists, fantasy points, wishlists and the pick timer, host tools, team identity and captains). Each file runs in a single transaction that inserts temporary `auth.users`, sets `request.jwt.claim.sub` to act as them, and always rolls back, so nothing persists. They read `SUPABASE_DB_URL` from the environment or `.env.local` (`scripts/dbUrl.cjs`); point it at staging. CI runs them on pushes to `main` once the `SUPABASE_DB_URL` repository secret is set (GitHub → Settings → Secrets and variables → Actions); without it the job just prints a note.
